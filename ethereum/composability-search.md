# Ethereum Cross-Protocol Composability Search

Status: discovery ledger, not a finding report. A candidate is promoted to a profitable loop only after the required state exists on a local latest-block fork and the complete settlement path returns positive net value after repayment, unwind costs, and gas.

## Search method

Enumerate DEX discrepancies and lending/settlement mechanisms independently. For every discrepancy, record what state, capital, asset, account, or contract call it needs. Then search both catalogs for protocols that can supply that input or pay for the resulting state change. Continue across additional protocols where an edge is missing. A source defect, a reproduced state mutation, and a profitable composed loop are separate statuses.

A fresh API read on 2026-11-26 still returned 80 Ethereum GeckoTerminal DEX IDs.
- No lending report directory is present in this workspace. Existing lending protocol reviews and screens are tracked in the research history and must not be inferred from DEX report coverage.
